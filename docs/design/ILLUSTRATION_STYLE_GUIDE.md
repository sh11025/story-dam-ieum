# Story Dam Ieum Illustration Style Guide

## 기준

- 최우선 기준 이미지는 `초기/캐릭터 컨셉.png`, 화면 배치 기준은 `초기/UI컨셉.png`이다.
- 기존 담이 PNG/GIF를 캐릭터 원본으로 사용한다. 배경을 별도 생성 이미지로 교체하지 않는다.

## 공통 스타일

- 따뜻한 2D 그림책 표현. 단순하고 둥근 실루엣, 부드러운 곡선, 낮은 질감.
- 브랜드 팔레트: 딥 틸 `#287271`, 메인 브라운 `#C47A3A`, 베이지 `#F5E6D3`, 진한 브라운 `#5A3A24`, 민트 `#F2F8F7`.
- 자연색은 차분한 초록·하늘색·물색을 사용하고 화면마다 같은 오브젝트에 같은 팔레트를 쓴다.
- 담이는 원본의 가장 강한 외곽선, 다리와 통나무는 중간 굵기의 따뜻한 갈색 외곽선, 먼 언덕·구름은 약한 경계 또는 단순 면으로 깊이를 만든다.

## 오브젝트 규칙

- 강은 부드러운 청록 계열 면과 짧고 둥근 물결 선을 쓴다. 강둑은 둥근 곡선, 바위는 단순한 덩어리와 한 단계 밝은 면, 풀과 나무는 둥근 잎 덩어리로 표현한다.
- 다리와 설치 통나무는 `src/components/illustration/StoryWorld.tsx`의 `BridgeLog`/`StoryBridge`를 공유한다. 같은 나무색, 두께, 간격, 윤곽을 유지한다.
- 로그인·홈·진행률·완료 화면은 `StoryLandscape`, `StoryRiver`, `RiverBank`, `StoryBridge`를 재사용하고 구도만 조정한다.
- 담이와 나무·돌·통나무의 비율은 같은 SVG viewBox 구성 안에서 유지한다. 진행 담이 애니메이션 원본은 기존 자산 그대로 둔다.

## 금지

- 사진·3D·실사 질감·수채화 질감·픽셀아트·강한 그라데이션·네온 팔레트.
- 화면마다 별도로 만든 강·나무·다리, 이모지로 대체한 자연 사물, 서로 다른 외부 일러스트 자산 혼합.
- UI 입력창·버튼을 그림책 사물처럼 꾸미는 것. UI는 읽기 쉽고 단정하게 유지한다.

## 검토 기준

새 일러스트는 담이와 외곽선·색상·곡선이 어울리는지, 주요 장면에서 같은 강과 다리가 이어지는지, 1920×1080과 1366×768에서 배치가 유지되는지 확인한다. 화면 캡처와 실제 브라우저 확인 사실을 DEV_LOG에 기록하고 생성물은 앱 적용 전에 시각 검토한다.
